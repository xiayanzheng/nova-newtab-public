# Privacy policy

Nova New Tab stores its settings, shortcuts, and wallpaper on your device. It does not sell user data and does not send data to the developer.

If you add an Unsplash access key, that key is sent only to Unsplash to download a wallpaper. If you add a GitHub token and choose to sync, that token is sent only to GitHub so the page can read and save your config in the repository you name. The token and the Unsplash key are not written into the saved config.

Search opens the engine you picked in a new tab. The extension does not keep a history of pages you visit, clicks, or keystrokes.

# 隐私权政策

Nova New Tab 把设置、快捷方式和壁纸保存在你的设备上。扩展不出售用户数据，也不把数据发给开发者。

如果你填写 Unsplash 密钥，该密钥只发给 Unsplash，用来下载壁纸。如果你填写 GitHub 令牌并选择同步，该令牌只发给 GitHub，用来在你指定的仓库里读取和保存页面配置。令牌和 Unsplash 密钥不会写入保存的配置文件。

搜索会在新标签页打开你选择的搜索引擎。扩展不记录你访问过的网页、点击或按键。
