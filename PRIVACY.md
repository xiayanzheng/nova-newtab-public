# Nova New Tab Privacy Policy

Last updated: 28 September 2026

## Introduction

Thank you for using Nova New Tab. Nova New Tab is a browser extension that replaces the new tab page with a personal start page. It includes a clock, search, shortcuts, folders, and wallpapers.

This policy explains what information the extension uses, where that information stays, and when it leaves your device. Nova New Tab does not operate its own account system or its own server. It does not sell personal information.

Please read this policy before you use the extension. If you do not agree with it, uninstall the extension and remove its saved data from the browser.

This policy covers:

3. Cookies and similar technologies
4. Advertising and affiliate links
5. How information is stored
6. How information is shared

## 1. Why information is used

Information is used only to show and remember your new tab page:

- keep the clock, search box, shortcuts, folders, and wallpaper you set up
- open a search on the engine you choose
- show an icon for a shortcut you add
- download a wallpaper from Unsplash, only if you add your own Unsplash access key
- save or load your page setup in a GitHub repository, only if you add your own GitHub token and choose sync

The extension does not use information to advertise, to score credit, or for any purpose unrelated to the new tab page.

## 2. Information the extension uses

The extension does not ask you to register, and it does not ask for your name, phone number, email address, or payment details.

### Information kept on your device

The following stay in your browser’s local storage until you change them, reset the page, or remove the extension:

- layout and appearance settings
- shortcuts you add, including the name, address, icon, and folder arrangement
- search engines you add or select
- the wallpaper you choose, including a picture you upload
- an Unsplash access key, if you choose to enter one
- a GitHub repository name and token, if you choose to enter them

### Authentication information you choose to enter

An Unsplash access key and a GitHub token are credentials. They are optional.

- If you add an Unsplash access key, that key is sent only to Unsplash, together with the wallpaper search words you set, so Unsplash can return a photo. The key is not written into the configuration file.
- If you add a GitHub token and use sync, that token is sent only to GitHub so the extension can read and write the repository you named. The token is not written into the configuration file.

If you do not enter these credentials, those network features stay off.

### Search

When you submit a search, your browser opens the search engine you selected and sends your search words to that engine. Nova New Tab does not keep a list of your searches and does not send them to the developer.

### Shortcut icons and wallpapers

To draw a shortcut icon, the page may request that site’s icon from a public favicon service. The request contains the site address you added. A wallpaper address you paste is loaded by the browser so the picture can be shown. These requests are not stored by the developer.

### Information the extension does not collect

Nova New Tab does not collect health information, financial or payment information, personal messages, your location, a history of pages you visit, click or mouse records, or keystroke logs. It does not read the contents of other websites you open.

## 3. Cookies and similar technologies

Nova New Tab does not set cookies and does not use cookies to recognize you. Settings are stored in the browser’s local storage on your device, not in a cookie.

## 4. Advertising and affiliate links

Nova New Tab does not show ads and does not include affiliate links. Shortcuts go to the addresses you set, or to the built-in addresses shipped with the extension. The extension does not rewrite links on other websites.

## 5. How information is stored

Your new tab setup is stored on your device. Nova New Tab does not copy that setup to a server run by the developer.

If you turn on GitHub sync, a copy of the page configuration is stored in the GitHub repository you name. That copy can include settings, shortcuts, search engines, and wallpaper or icon image files. It does not include your GitHub token or your Unsplash access key. How long GitHub keeps that repository is controlled by your GitHub account, not by this extension.

You can delete the local data by resetting the page inside the extension or by removing the extension in the browser. Removing the extension does not delete a repository you already saved on GitHub. Delete that repository in GitHub if you want it gone.

## 6. How information is shared

Nova New Tab does not sell personal information and does not transfer it to data brokers.

Information leaves your device only in these cases:

- you search, and your browser sends the search words to the engine you selected
- you add an Unsplash key, and the extension sends that key and your wallpaper search words to Unsplash
- you add a GitHub token and use sync, and the extension sends that token and your page configuration to GitHub
- the page loads a shortcut icon or a wallpaper picture from the address needed to display it

Unsplash, GitHub, the search engine you pick, and any site that hosts an icon or wallpaper handle those requests under their own policies.

The developer does not receive the contents of these requests.

## 7. How information is protected

Credentials and page settings stay in the browser profile on your device. The GitHub token is sent to GitHub over HTTPS and is left out of the saved configuration file. The Unsplash key is sent to Unsplash over HTTPS and is left out of the saved configuration file.

No method of storage or transmission is perfectly secure. Keep your GitHub token and Unsplash key private, and do not sync to a public repository if the configuration contains anything you do not want others to see.

## 8. Your choices

You can use the new tab page without an Unsplash key and without a GitHub token. Those fields are optional.

You can edit or delete shortcuts, change or clear the wallpaper, replace or remove the Unsplash key, and replace or remove the GitHub token in the extension settings. You can reset the page to its default setup. You can uninstall the extension at any time.

## 9. Changes to this policy

If this policy changes, the updated text will replace this page and the date at the top will change. Continued use of the extension after the update means you accept the updated policy.

## 10. Minors

Nova New Tab is a general new tab page. It is not directed at children. If you are under the age required by the laws of your place of residence, use the extension only with a parent or guardian.

## 11. Contact

Questions about this policy can be sent through the public repository:

# Nova New Tab 隐私权政策

最近更新：2026 年 9 月 28 日

## 简介

感谢使用 Nova New Tab。Nova New Tab 是一个浏览器扩展，用个人起始页替换新标签页。页面包含时钟、搜索、快捷方式、文件夹和壁纸。

本政策说明扩展会使用哪些信息、这些信息留在哪里，以及何时会离开你的设备。Nova New Tab 没有自己的账号系统，也没有自己的服务器。扩展不出售个人信息。

使用扩展前请阅读本政策。如果你不同意，请卸载扩展，并在浏览器中清除它保存的数据。

## 1. 为什么使用信息

信息只用于显示并记住你的新标签页：

- 保留你设置的时钟、搜索框、快捷方式、文件夹和壁纸
- 用你选择的搜索引擎打开搜索
- 显示你添加的快捷方式图标
- 仅在你填写自己的 Unsplash 密钥后，从 Unsplash 下载壁纸
- 仅在你填写自己的 GitHub 令牌并选择同步后，把页面配置保存到你指定的 GitHub 仓库，或从该仓库读取

扩展不会把信息用于广告、信用评估，或与新标签页无关的目的。

## 2. 扩展会使用的信息

扩展不要求注册，也不索取姓名、电话、电子邮件或付款信息。

### 留在你设备上的信息

以下内容保存在浏览器的本地存储中，直到你修改、重置页面或移除扩展：

- 布局和外观设置
- 你添加的快捷方式，包括名称、地址、图标和文件夹
- 你添加或选中的搜索引擎
- 你选择的壁纸，包括你上传的图片
- 你主动填写的 Unsplash 密钥
- 你主动填写的 GitHub 仓库名和令牌

### 你选择填写的身份验证信息

Unsplash 密钥和 GitHub 令牌属于凭证，都是可选项。

- 如果你填写 Unsplash 密钥，该密钥只会和你设置的壁纸搜索词一起发给 Unsplash，用来获取一张图片。密钥不会写入配置文件。
- 如果你填写 GitHub 令牌并使用同步，该令牌只会发给 GitHub，用来读写你指定的仓库。令牌不会写入配置文件。

如果不填写这些凭证，对应的网络功能保持关闭。

### 搜索

你提交搜索时，浏览器会打开你选中的搜索引擎，并把搜索词发给该引擎。Nova New Tab 不保存搜索记录，也不把搜索词发给开发者。

### 快捷方式图标和壁纸

为了画出快捷方式图标，页面可能向公开的网站图标服务请求该网站的图标。请求里包含你添加的网站地址。你粘贴的壁纸地址由浏览器加载，以便显示图片。开发者不会保存这些请求。

### 扩展不收集的信息

Nova New Tab 不收集健康信息、财务或付款信息、个人消息、位置、访问过的网页列表、点击或鼠标记录、按键记录。扩展也不读取你打开的其他网站的内容。

## 3. Cookie 及类似技术

Nova New Tab 不设置 Cookie，也不用 Cookie 识别你。设置保存在浏览器的本地存储中，不是 Cookie。

## 4. 广告和联盟链接

Nova New Tab 不展示广告，也不包含联盟链接。快捷方式指向你设置的地址，或扩展自带的地址。扩展不会改写其他网站上的链接。

## 5. 信息如何保存

新标签页的配置保存在你的设备上。Nova New Tab 不会把这份配置复制到开发者的服务器。

如果你打开 GitHub 同步，页面配置的一份副本会保存在你指定的 GitHub 仓库里。这份副本可以包含设置、快捷方式、搜索引擎，以及壁纸或图标图片。它不包含 GitHub 令牌，也不包含 Unsplash 密钥。GitHub 保留该仓库多久，由你的 GitHub 账号决定，不由本扩展决定。

你可以在扩展里重置页面，或在浏览器中移除扩展，从而删除本地数据。移除扩展不会删除你已经保存到 GitHub 的仓库。如果要删除那份副本，请在 GitHub 中删除该仓库。

## 6. 信息如何共享

Nova New Tab 不出售个人信息，也不把个人信息交给数据经纪商。

信息只在以下情况离开你的设备：

- 你进行搜索，浏览器把搜索词发给你选中的搜索引擎
- 你填写了 Unsplash 密钥，扩展把该密钥和壁纸搜索词发给 Unsplash
- 你填写了 GitHub 令牌并使用同步，扩展把该令牌和页面配置发给 GitHub
- 页面为了显示快捷方式图标或壁纸而加载对应地址

Unsplash、GitHub、你选择的搜索引擎，以及托管图标或壁纸的网站，按它们自己的政策处理这些请求。

开发者不会收到这些请求的内容。

## 7. 信息如何保护

凭证和页面设置留在你设备上的浏览器配置中。GitHub 令牌通过 HTTPS 发给 GitHub，并且不会写入保存的配置文件。Unsplash 密钥通过 HTTPS 发给 Unsplash，并且不会写入保存的配置文件。

没有任何保存或传输方式是绝对安全的。请保管好 GitHub 令牌和 Unsplash 密钥。如果配置里有你不希望别人看到的内容，不要同步到公开仓库。

## 8. 你可以做的选择

不填写 Unsplash 密钥和 GitHub 令牌，也可以使用新标签页。这两项都是可选的。

你可以在扩展设置里编辑或删除快捷方式，更换或清除壁纸，更换或删除 Unsplash 密钥，更换或删除 GitHub 令牌。你可以把页面重置为默认设置，也可以随时卸载扩展。

## 9. 政策变更

如果本政策有变更，新文本会替换本页，并更新页首日期。更新之后继续使用扩展，即表示你接受更新后的政策。

## 10. 未成年人

Nova New Tab 是一般用途的新标签页，不以儿童为对象。如果你未达到所在地法律要求的年龄，请在父母或监护人陪同下使用。
